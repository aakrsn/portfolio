### About

- This project is about building a Professional Portfolio Website for me.

### Purpose

- The purpose of this project is to build a Professional Portfolio Website which can help me identifying and shortlisted in Full Time and Freelance Job Oppourtunities.

### Project Requirements

- The Website should capture all of my skills and experience completely and project/market them well.
- Should be Simple, Good Looking and Professional.
- Should Follow the Standards of a Successfull Tech Professional Portfolio which gets them Job Oppourtunities.
- Should be Deployed in Public.
- The Development of this Project should happen in a Systematic Way
    - Must have System Architecture before implementation.
    - Every implementation should align with System Architecture, If any new features need to be added the implementation should start only after updating Architecture.
    - Should have the Desgin of the UI.
    - Should Maintain a git based repository, Should Properly commit and push each feature.
    - The Code Should not be OverEngineered or Overly Complicated. The Code should not be filled with unnecessary checks.
    - The Logic should also be simple no unnecessary complication.
    - Backend and Frontend Component or Folders should be in Different Place. Needs to be developed independently and then to be merged.
- Every Feature implementation should follow the cycle of Research, Literature Review, Planning and Execution when ever applicable.

### Tech Stack

- For most of the cases the following tech stack need to be used if anything else is required the permission needs to be taken
    - Programming Language : Python
    - Backend : FastAPI
    - Frontend : HTML, CSS (Java Script if required)

#### Design preferences

- Provide light and dark modes with a theme switch.
- Use only pure white, pure black, and one deep saturated orange in both modes.
- Use the supplied screenshot as a reference for bold, tall condensed lettering. Set the name in deep orange directly on the page background.
